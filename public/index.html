What It Provides

Live Kubernetes Reads

Pods, deployments, services, events, workloads, PVCs, ingresses, findings and metrics summaries.

Read-Only Diagnostics

Bounded Kubernetes API tools gather logs, pod details, events, PVC and endpoint evidence without shell access.

Optional Agentic AI

Natural-language chat uses a Strands diagnostic agent on Bedrock to choose bounded read-only tools. Disabled by default.

Install

1. Add The Repository

helm repo add kubeops-insight https://yosoyfunes.github.io/kubeops-insight
helm repo update

2. Install Helm Chart

helm upgrade --install kubeops-insight kubeops-insight/kubeops-insight \
  --namespace kubeops-insight \
  --create-namespace

Bedrock is the default LLM provider. For EKS, annotate the ServiceAccount with an IRSA role that can invoke Bedrock.

Bedrock With IRSA

helm upgrade --install kubeops-insight kubeops-insight/kubeops-insight \
  --namespace kubeops-insight \
  --create-namespace \
  --set serviceAccount.annotations.eks\.amazonaws\.com/role-arn=arn:aws:iam::123456789012:role/KubeOpsInsightBedrockIrsaRole

Access The Dashboard

kubectl -n kubeops-insight port-forward svc/kubeops-insight-kubeops-insight-frontend 5173:80

Open http://localhost:5173. Default username is admin. The initial password is generated in the chart-managed Secret.

kubectl -n kubeops-insight get secret kubeops-insight-kubeops-insight-auth \
  -o jsonpath='{.data.password}' | base64 --decode

Common Options

Use caseValues
Install Metrics Server--set metrics.metricsServer.install=true
Ingress--set ingress.enabled=true --set ingress.hosts[0].host=kubeops.example.com
Bedrock--set llm.provider=bedrock
IRSA--set serviceAccount.annotations.eks\.amazonaws\.com/role-arn=arn:aws:iam::123456789012:role/KubeOpsInsightBedrockIrsaRole
Agent limits--set llm.agent.maxCycles=5 --set llm.agent.timeoutSeconds=30
OIDC--set auth.oidc.enabled=true plus issuer, client ID, redirect URI and Secret.

Security Defaults

Read-only RBAC

The backend reads Kubernetes state and pod logs. Mutating actions are disabled by default.

No Shell Execution

AI investigations use curated Kubernetes API tools, not arbitrary commands.

Hardened Pods

Non-root execution, read-only root filesystem defaults, NetworkPolicy and PDB templates.
